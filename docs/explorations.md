# Photo-to-art explorations · 照片创意实验室

[English guide](../README.md) · [中文指南](../README.zh-CN.md)

17 directions, one beach photograph. These are real creative drafts, not a promise of identical results.

17 种方向，同一张海滩照片。这些是实际生成的创意样张，供挑选，不代表每张照片都能复现相同效果。
原有 7 种风格有海滩、咖啡露台、树下街巷案例；本页的新方向目前仅做海滩探索。

![Source beach photo with three seated companions](../assets/examples/source-beach-sunset.webp)

## Try a direction · 试一种画法

Attach your photo and name a direction; the Skill reads the matching study prompt below.

```text
用 $albert-imagebook，把这张照片做成探索版「蓝线贴纸」，不加字。
Use $albert-imagebook. Try the experimental pixel-coast style on this photo.
```

Prompts below are reusable directions distilled from the study. The linked images were made with
the original beach-specific prompts; the reusable versions have not been separately regenerated.
生成和排版使用共享 Skill 流程；提示词已从海滩首稿提炼为通用方向，尚未单独回归验证。
65% 是构图指导而非自动测量保证；部分首稿偏满，蓝晒和漫画的表现也有继续改进空间。
字景需指定文字；其他方向默认不加新字。

### 01 · 日常贴贴

`little-day-stickers`

[Original + artwork · 上下对照](assets/exploration/little-day-stickers-comparison.webp)

<details>
<summary>Reusable study prompt · 探索版提示词</summary>

Read the source photo for its defining subject, pose and relationships. Preserve those facts.
Adapt the following material and graphic language to the supplied scene; do not import beach
objects into an unrelated photo. Omit motifs that do not belong to the source.

Create a small die-cut sticker set: one main sticker for the key subject, with up to two smaller motifs drawn from the same photograph. Use natural proportions, flat buttery yellow, dusty navy, coral and seafoam, dark-blue contours and narrow ivory cut rims. Keep generous gaps and tiny contact shadows. No giant cartoon heads, emojis, glitter or enclosing rectangle. This is a visual concept, not a production cutting file.
