# Painterly Stories · Painterly Photo Illustration

[← Albert’s Imagebook](../../README.md) · [简体中文](README.zh-CN.md) · [Full prompt](prompt.md)

**Broad brushwork · color planes · movement**

Retell the movement and atmosphere of a photograph with a few expressive painted shapes.

![Painterly Stories: Broad brushwork · color planes · movement](assets/beach-centered-artwork.webp)

## The signature

Broader gestures and layered color than Quiet Acrylic, with more emphasis on motion and depth.

**Best for:** Street life, gestures, people in architecture.

## Try your own photo

Install [Albert’s Imagebook](../../README.md#get-started), start a new session, and attach a photo:

```text
Use $albert-imagebook. Turn this photo into Painterly Stories, no text.
```

The default is a 1080×1440 portrait artwork. To reproduce this page's comparison layout, ask:

```text
Use Painterly Stories, top-bottom, original above artwork, 50:50, 1080×1440, no text.
```

## Original → artwork

![Beach sunset: original above artwork](assets/beach-centered-comparison.webp)

[Original photo](../../assets/examples/source-beach-sunset.webp) · [Standalone artwork](assets/beach-centered-artwork.webp)

The comparison is 1080×1440, exactly half each; the standalone artwork is 1080×720. The original
fills its half with a west-anchored crop that keeps all three people. Paper, marks and broken
edges are generated together and preserved on export, with no added mat or separator bars.
No new text is added.
