# Enamel Keepsake · Photo to Enamel Miniature

[← Albert’s Imagebook](../../README.md) · [简体中文](README.zh-CN.md) · [Full prompt](prompt.md)

**Tiny keepsake · metal outlines · enamel sheen**

Keep a memorable silhouette as a small enamel object with real thickness and a soft glint.

![Enamel Keepsake: Tiny keepsake · metal outlines · enamel sheen](assets/beach-artwork.webp)

## The signature

One tangible object with metal boundaries, a contact shadow, and a source-colored background.

**Best for:** Landmarks, architecture, distinctive silhouettes.

## Try your own photo

Install [Albert’s Imagebook](../../README.md#get-started), start a new session, and attach a photo:

```text
Use $albert-imagebook. Turn this photo into Enamel Keepsake, no text.
```

The default is a 1080×1440 portrait artwork. To reproduce this page's comparison layout, ask:

```text
Use Enamel Keepsake, top-bottom, original above artwork, 50:50, 1080×1440, no text.
```

## Original → artwork

![Beach sunset: original above artwork](assets/beach-comparison.webp)

[Original photo](../../assets/examples/source-beach-sunset.webp) · [Standalone artwork](assets/beach-artwork.webp)

The comparison is 1080×1440, exactly half each; the standalone artwork is 1080×720. The original
fills its half with a west-anchored crop that keeps all three people. Paper, marks and broken
edges are generated together and preserved on export, with no added mat or separator bars.
No new text is added.
