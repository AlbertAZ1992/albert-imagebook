# Little Day Stickers · 日常贴贴

A small sticker set drawn from the people, gestures and objects that define the photograph.
把照片里最有记忆点的人物、动作和物件，收成一组轻巧的日常贴纸。

Keywords: Die-cut stickers · flat color · small motifs.
关键词：模切贴纸 · 平涂色块 · 小型图案。
Also known as: Sticker Set · 日常贴纸.

## Prompt

Read the source photo for its defining subject, pose and relationships. Preserve those facts.
Adapt the material and graphic language to the supplied scene; do not import motifs that do
not belong to the source.

Create a small die-cut sticker set: one main sticker for the key subject, with up to two smaller
motifs drawn from the same photograph. Use natural proportions, flat buttery yellow, dusty navy,
coral and seafoam, dark-blue contours and narrow ivory cut rims. Keep generous gaps and tiny
contact shadows. No giant cartoon heads, emojis, glitter or enclosing rectangle. This is a
visual concept, not a production cutting file.
